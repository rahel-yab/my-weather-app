# WeatherApp 🌤️

A responsive weather web application that displays real-time weather data for searched cities using the OpenWeatherMap API.

## Features 🌟
- **City Search**: Get weather by city name or ZIP code
- **Current Conditions**: 
  - Temperature (°C/°F toggle)
  - Humidity 
  - Wind speed 
  - Weather description
- **Responsive Design**: Works on mobile, tablet & desktop
- **Dynamic Backgrounds**: Changes based on weather conditions

## Technologies Used 💻
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **API**: [OpenWeatherMap API](https://openweathermap.org/api)
- **Icons**: [Weather Icons](https://erikflowers.github.io/weather-icons/)
- **Hosting**: GitHub Pages
